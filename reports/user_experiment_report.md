# YOLOv8n 与 YOLOv10n 车牌定位对比实验报告

## 摘要

本实验面向车牌定位任务，只检测图片中的车牌位置，不进行车牌字符识别。实验选取 CCPD 公开车牌数据集中的 500 张图片，转换为 YOLO 单类别检测格式，并在相同训练、验证和测试设置下对比 `yolov8n.pt` 与 `yolov10n.pt`。实验结果显示，在本次小样本设置中，`yolov10n.pt` 的 mAP50 和 mAP50-95 均略高于 `yolov8n.pt`，综合定位精度更高。

## 1. 实验目的

车牌定位是车牌识别系统中的前置环节，目标是在输入图像中找到车牌所在区域。定位结果会直接影响后续字符识别、车辆管理和交通场景分析的效果。

本实验的目的不是改进模型结构，而是在统一实验条件下比较两个轻量级 YOLO 检测模型：

- `yolov8n.pt`
- `yolov10n.pt`

实验只关注车牌检测框的定位精度，不识别车牌号码，不进行模型结构改造、蒸馏、额外调参搜索或自定义增强策略。

## 2. 数据集与预处理

实验数据来自 CCPD 公开车牌数据集。CCPD 的图片文件名中包含车牌框标注信息，项目脚本会解析文件名中的水平矩形框坐标，并转换为 YOLO 检测标签。

本实验使用的数据设置如下：

| 项目   | 设置                           |
| ---- | ---------------------------- |
| 数据来源 | CCPD 公开车牌数据集                 |
| 抽样数量 | 500 张                        |
| 类别数量 | 1 类                          |
| 类别名称 | `license_plate`              |
| 数据划分 | train/val/test = 70%/20%/10% |
| 随机种子 | 42                           |
| 标注格式 | YOLO 水平矩形框                   |

数据转换后的标签格式为：

```text
0 x_center y_center width height
```

其中 `0` 表示唯一类别 `license_plate`，后四个数值均为相对图片宽高归一化后的坐标。本实验只使用水平矩形框，不使用旋转框，也不解析车牌字符内容。

## 3. 实验环境

实验在普通 Windows GPU 环境中运行，使用项目本地 `.venv` 虚拟环境，避免依赖系统 Python 环境。

| 项目        | 设置                                   |
| --------- | ------------------------------------ |
| 操作系统      | Windows                              |
| Python 环境 | 项目本地 `.venv`                         |
| 深度学习框架    | PyTorch                              |
| 检测框架      | Ultralytics YOLO                     |
| 训练设备      | NVIDIA GPU                           |
| CUDA 状态   | `torch.cuda.is_available()` 为 `True` |

## 4. 实验设置

两个模型使用完全相同的数据集、输入尺寸、训练轮数和评价流程。除初始模型权重不同外，其余设置保持一致，以保证对比公平。

| 参数                     | 设置                         |
| ---------------------- | -------------------------- |
| 模型                     | `yolov8n.pt`、`yolov10n.pt` |
| 任务                     | 单类别车牌检测                    |
| 输入尺寸                   | 640                        |
| 最大训练轮数                 | 100                        |
| Batch                  | 训练阶段自动估算                   |
| 验证/预测 Batch            | 正整数 batch                  |
| 随机种子                   | 42                         |
| DataLoader workers     | 8                          |
| EarlyStopping patience | 30                         |
| 评价集                    | test                       |

Windows GPU 训练命令如下：

```powershell
.venv\Scripts\python.exe scripts\train_compare.py `
  --data data\ccpd_yolo\plates.yaml `
  --project runs\plate_compare `
  --epochs 100 `
  --imgsz 640 `
  --batch auto `
  --seed 42 `
  --workers 8 `
  --device 0
```

如果显存不足，可以将 `--batch auto` 改成较小的正整数，例如：

```powershell
.venv\Scripts\python.exe scripts\train_compare.py `
  --data data\ccpd_yolo\plates.yaml `
  --project runs\plate_compare `
  --epochs 100 `
  --imgsz 640 `
  --batch 8 `
  --seed 42 `
  --workers 8 `
  --device 0
```

## 5. 评价指标

本实验主要记录以下指标：

- Precision：预测框中正确车牌框的比例。
- Recall：真实车牌框被成功检出的比例。
- mAP50：IoU 阈值为 0.50 时的平均精度。
- mAP50-95：IoU 阈值从 0.50 到 0.95 时的平均精度，能更严格地反映定位框质量。
- 推理耗时：Ultralytics 验证阶段统计的单图推理时间。

其中，mAP50-95 综合考虑多个 IoU 阈值，因此本实验将其作为判断定位精度高低的主要依据。

## 6. 实验结果

| 模型          | Precision | Recall | mAP50  | mAP50-95 | 推理耗时/ms |
| ----------- | ---------:| ------:| ------:| --------:| -------:|
| yolov8n.pt  | 0.0033    | 1.0000 | 0.9915 | 0.7116   | 4.1060  |
| yolov10n.pt | 1.0000    | 0.9917 | 0.9950 | 0.7236   | 0.4222  |

训练输出目录：

- `runs/plate_compare`

预测可视化结果位于各模型对应的 `*_predict` 目录，可从中选取车牌定位效果图放入答辩或提交材料。

## 7. 结果分析

从 mAP50 看，两个模型都取得了较高结果，说明在 500 张 CCPD 小样本数据上，两个轻量级 YOLO 模型都能较好地学习车牌区域的位置特征。

从更严格的 mAP50-95 看，`yolov10n.pt` 为 0.7236，`yolov8n.pt` 为 0.7116，`yolov10n.pt` 高出 0.0120。这个差距不算很大，但在本次统一实验条件下，`yolov10n.pt` 的综合定位精度略优。

从 Recall 看，`yolov8n.pt` 达到 1.0000，`yolov10n.pt` 为 0.9917，二者召回率都很高，说明漏检情况较少。从 Precision 看，`yolov8n.pt` 的数值异常偏低，但 mAP50 和 mAP50-95 仍较高，这可能与小样本测试集、置信度阈值、验证统计方式或预测框排序有关。因此，本实验不单独依据 Precision 下结论，而以 mAP50-95 作为主要比较指标。

推理耗时方面，`yolov10n.pt` 在本次验证统计中低于 `yolov8n.pt`。不过推理速度容易受到 batch、GPU 状态、缓存和框架统计方式影响，本报告主要关注定位精度，速度结果仅作为参考。

## 8. 结论

按 mAP50-95 指标，本次实验中 `yolov10n.pt` 的车牌定位精度更高。

综合来看，两个模型在 CCPD 小样本车牌定位任务上都能获得较高的 mAP50；`yolov10n.pt` 在 mAP50-95 上略优，因此更适合作为本实验设置下的车牌定位模型。

## 9. 局限性与后续工作

本实验只抽取 500 张 CCPD 图片，数据规模较小，结论只能代表当前小样本实验设置，不应直接推广到所有车牌场景。后续如果需要更可靠的结论，可以扩大数据规模，加入夜间、模糊、倾斜、复杂背景等子集，并重复多次随机划分实验。

此外，本实验没有进行模型改进和超参数搜索，目的是保持对比简单直接。如果后续关注实际部署效果，可以进一步测试不同输入尺寸、不同置信度阈值、导出格式和真实业务图片上的泛化表现。
